# Quick iPhone Setup

Your audio player works great on iPhone! Here's the fastest way:

## Step 1: Start Server on Mac

```bash
cd ~/DUXTest/audio_player
python3 -m http.server 8000
```

## Step 2: Find Your Mac's IP

**Mac:** System Settings → Network → Wi-Fi → Details

Look for IP Address (like `192.168.1.5`)

## Step 3: Open on iPhone

1. Open **Safari** on iPhone (not Chrome!)
2. Type: `http://192.168.1.5:8000` (use your actual IP)
3. Tap Play button to start listening

## Step 4: Add to Home Screen (Optional)

1. Tap Share button ⬆️ in Safari
2. Scroll down → "Add to Home Screen"
3. Name it "UX News" and tap Add
4. Now launch from home screen like an app!

## Features on iPhone

✅ High-quality iOS voices
✅ Works with screen locked
✅ Lock screen controls
✅ AirPods compatible
✅ Full touch controls
✅ Responsive design

## Tips

- **Use Safari only** - Chrome doesn't support speech on iOS
- **Allow first play** - Tap play button to start
- **Works in background** - Lock screen and it keeps playing
- **Best with AirPods** - Connect before starting
